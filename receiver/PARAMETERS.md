# 接收机参数依据

参数优先遵循用户最新确认的保留项、可编辑状态及默认值，其余依据用户提供的《接收机配置.docx》第 6.5 节及图 1、《接收机SCPI指令集.docx》第 2.2 节。`signal_analyse` 仅作为输入控件、配色和频谱交互的样式参考，不作为设备参数依据。

| 参数 | 当前配置及处理 | 文档依据 |
| --- | --- | --- |
| 中心频率 | 手动输入 0～8000 MHz；初值 2000 MHz | 用户最新明确范围，覆盖之前使用的 20 MHz 下限 |
| 频谱带宽 | 固定下拉选项：2、5、10、20、40、80、160、320 MHz；默认 320 MHz；禁止手动输入，配置下发前校验档位 | 用户确认的实际设备能力 |
| 频谱步进 | 仅 12.5、25、50、100、200 kHz；默认 12.5 kHz | 用户最新明确选项；用于中心频率上下方向键调谐 |
| 参考电平 | −256～256 dBµV；初值 120 | 配置 6.5、图 1；本地纵轴参数 |
| 电平跨度 | 1～50 dB/格；初值 20；固定十格 | 配置文档电平跨度说明及图 1；删除从参考项目引入的“间隔数量” |
| XdB 带宽 | 0～100 dB；初值 26；下发 MEASure:BANDwidth:XDB | SCPI 2.2.22 |
| β% 带宽 | 按用户最新确认：允许 0～99.9%，默认 0；按填写值下发 MEASure:BANDwidth:BETA | 用户明确要求默认 0，覆盖此前按手册设置的 0.1 下限和 1 初值 |
| 解调模式 | IQ、AM、FM、CW、LSB、USB、PULSE、PM、DMR、DPMR；中文显示；初值 FM | SCPI 2.2.14 的参数解释及 2.2.25；2.2.14 命令签名有 PLUSE 拼写差异，使用参数解释中的 PULSE |
| 解调带宽（高级参数） | 500、300、250、150、120、50、30、15、12、9、6、2.4、1.5 kHz；初值 500 kHz；不能大于频谱带宽 | SCPI 2.2.8。手册说明选项包括但不限于这些值、实际能力视设备而定。当前使用手册列出的解调带宽预设 |
| 自动增益、射频/中频衰减 | 自动增益初始关闭；衰减 0～50 dB、初值 0；自动增益开启时禁用手动衰减 | SCPI 2.2.9、2.2.11、2.2.12；不套用其他模式的 30/20 dB 控件上限 |
| 射频模式 1 | 正常、低噪声、低失真；初值正常 | SCPI 2.2.13 |
| 测量时间 | 0～10000 ms；初值 0.5 ms（500 µs）；先下发自动测量时间关闭，再发送时间 | SCPI 2.2.19、2.2.20；图 1 初值 |
| 检波方式 | 快速、正峰值、平均值、均方根；初值正峰值 | SCPI 2.2.21；图 1 |
| DPX 刷新时间 | 初值 100 ms，当前控制频谱和瀑布图本地刷新间隔 | 图 1；当前无 DPX 荧光谱实现，不声称下发 DPX 命令 |

## 用户确认的参数调整

- 删除参考时钟、电平触发、触发电平、静噪门限、射频模式 2、高性能模式、回放速度、红色占有率的输入与配置字段。
- 按用户最新要求删除频率偏移及其配置字段，不再发送 FREQuency:OFFSet。
- 解调带宽移至高级参数，与解调模式放在一起。
- 静噪开关保留，但不再发送已移除的门限参数。
- 按用户最新要求删除射频输出模式及其配置字段。

## 显示功能

按用户要求保留实时、最大保持、最小保持、平均以及缩放交互。平均次数只属于本地迹线处理，不作为设备测量参数下发。电平始终保留 dBµV，不转换为 dBm。
